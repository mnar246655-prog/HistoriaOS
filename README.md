# HistoriaOS

منصة تاريخية عربية تفاعلية تحتوي على:

- مكتبة كتب تاريخية
- موسوعة شخصيات
- قاعدة أحداث تاريخية
- خرائط تفاعلية
- خطوط زمنية
- أطلس تاريخي تفاعلي متعدد الطبقات
- موسوعة الخلفاء الراشدين
- موسوعة الدولة الأموية
- صفحات تعريفية وتجارية
- تصدير للطباعة أو الحفظ بصيغة PDF

النسخة: 1.0

## تشغيل الموقع

لتحميل الكتب والشخصيات والأحداث من ملفات JSON، شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`؛ ستحولك الصفحة الرئيسية تلقائيًا إلى `website/index.html`. لا تفتح ملف HTML مباشرة؛ إذ تتطلب قراءة ملفات JSON تشغيل الموقع عبر خادم محلي.

تتضمن الواجهة صفحة رئيسية موسوعية وصفحة مستقلة للمراجع، إلى جانب صفحات الكتب والشخصيات والأحداث والخط الزمني. تعرض الرئيسية إحصاءات حية من بيانات الدولة الأموية ومختارات لا تشمل السجلات التجريبية، وتوضح نطاق التغطية. تشترك الصفحات في `website/styles.css` و`website/app.js`، ويُبنى الخط الزمني التفاعلي العام من `events/events.json` مع ترتيب الأحداث وإمكانية استعراضها حسب السنة.

صفحة `website/maps.html` هي الأطلس التاريخي التفاعلي: تعرض طبقات المدن والمواضع والمعارك ومراكز الدول والفتوحات والطرق التجارية التخطيطية، وتربطها بمؤشر زمني ووضع «عش الحدث». يضيف الوضع خطًا زمنيًا تفاعليًا من ست مراحل لكل معركة، ويعرض السياق والمواقع المرجعية والحركة والقرارات والنتائج مع إظهار فجوات التوثيق؛ لا يُنشئ مواقع أو أعدادًا أو قرارات غير مسندة. تعتمد الخريطة على Leaflet وبلاطات OpenStreetMap، ولذلك يلزم اتصال بالإنترنت. ويعمل المرشد محليًا بالبحث في السجلات، فيما يحتاج توليد الإجابات إلى خدمة خلفية آمنة لا تضع مفاتيح API في صفحات GitHub Pages. يمكن تهيئة عنوان خدمة على النطاق نفسه عبر `meta[name="historical-ai-endpoint"]`؛ ترسل الواجهة `POST { "question": "..." }` وتتوقع `{ "answer": "...", "citations": [{ "collection": "umayyad|rashidun", "id": "event-id", "label": "..." }] }`، وتتحقق من أن كل إحالة تطابق سجلًا معروفًا.

تقدم صفحة `website/visual-history.html` معرضًا بصريًا للشخصيات والمدن والمعارك والدول، يربط البطاقات الموسوعية بالخطوط الزمنية والأطلس. الرسوم داخل `assets/images/` أصلية وتجريدية وموسومة بوصفها تصورات، لا صورًا أرشيفية أو إعادة بناء تاريخية. تُعرض إحداثيات المعارك والمدن بوصفها مراجع جغرافية تقريبية، ويُذكر صراحة عند غياب الإحداثيات أو الإحالة.

تقدم صفحة `website/rashidun.html` موسوعة الخلفاء الراشدين: 4 سير و27 حدثًا و18 موضعًا، مع خط زمني تفاعلي وخريطة مرتبطة بالأحداث. تُولد البيانات ونسخة الكتاب من `rashidun/encyclopedia-content.js` بواسطة `scripts/generate-rashidun-data.js`، ويغطيها `RASHIDUN_ENCYCLOPEDIA.md` و`RASHIDUN_REPORT.md`.

تقدم صفحة `website/umayyad.html` موسوعة الدولة الأموية في المشرق (661–750م): نشأة وإنجازات وتأثيرًا تاريخيًا لكل شخصية، وروابطها بجميع الأحداث المرتبطة بها، وخلفية وأسبابًا ونتائج ومراجع لكل حدث. تضم البيانات 50 شخصية و100 حدث و20 مدينة و10 معارك، مع وصلات بين الخلفاء والولاة والقادة، وخط زمني وخريطة تفاعلية. يُعاد توليد البيانات والنسخة الكتابية من `scripts/generate-umayyad-data.js`؛ وتوجد النسخة القابلة للتحويل إلى كتاب في `UMAYYAD_ENCYCLOPEDIA.md`.

تربط الإحالات الأحداث بدراسات أكاديمية ومصادر أولية مترجمة، وتبقي روابط ويكيبيديا للقراءة التمهيدية فقط. لا تُذكر أرقام صفحات غير متحقق منها؛ وينبغي الرجوع إلى الطبعة المستخدمة قبل الاستشهاد البحثي.

لإعادة التوليد والتحقق:

```bash
node scripts/generate-umayyad-data.js
node scripts/generate-rashidun-data.js
node scripts/validate-launch.js
```

## البيانات

أزيلت السجلات التجريبية من مجموعات الكتب والشخصيات والأحداث. تضم البيانات العامة حاليًا 35 كتابًا و135 شخصية و233 حدثًا، إضافة إلى مجموعتي الدولة الأموية والخلافة الراشدة المتخصصتين. هذه الأعداد أقل من أهداف التحرير الحالية (100 كتاب، 200 شخصية، 500 حدث)؛ ولا تُعامل على أنها مكتملة. تتضمن الكتب قرن التأليف وروابط المصدر، وتضم الدفعة الأخيرة نصوصًا رقمية في ويكي مصدر؛ يُراجع بيان الحقوق في صفحة كل نص قبل إعادة استخدامه.

لإزالة أي عينات قديمة متبقية شغّل `node scripts/remove-sample-data.js`. لم يعد مولّد البيانات التجريبية موجودًا. يمكن إعادة استيراد المجموعة التحريرية الحالية بواسطة `node scripts/import-verified-content.js`؛ وهذا لا يملأ الأهداف العددية المذكورة أعلاه.

## التصدير والخطط

زر «طباعة / حفظ PDF» يستخدم نافذة الطباعة في المتصفح؛ اختر «حفظ كـ PDF». مجلد `exports` مخصص لحفظ الملفات يدويًا. صفحة الخطط تعريفية فقط: الدفع والاشتراكات ومزايا الخطة الاحترافية ليست مفعّلة. نموذج التواصل لا يرسل الرسائل حتى ربطه بخدمة استقبال.

## النشر على GitHub Pages

يوجد سير عمل في `.github/workflows/pages.yml` يفحص الملفات قبل النشر، ويستخدم إعداد GitHub Pages لتوليد عناوين SEO ومسار 404 الصحيح، ثم ينشر عند الدفع إلى فرع `main`. راجع [قائمة تحقق الإطلاق](LAUNCH_CHECKLIST.md) و[دليل النشر خطوة بخطوة](DEPLOY_GITHUB_PAGES.md).

للفحص المحلي قبل الدفع:

```powershell
node scripts/validate-launch.js
```

لتوليد ملفات SEO محليًا، عيّن `SITE_URL` إلى العنوان الأساسي المنشور ثم شغّل `node scripts/generate-seo.js`. راجع [الخطة التنفيذية السنوية](MASTER_PLAN.md) لاستراتيجية التحرير والمنتجات والنمو، و[خارطة الطريق](ROADMAP.md) للأولويات التشغيلية للأشهر الستة القادمة.
