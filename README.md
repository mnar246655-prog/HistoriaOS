# HistoriaOS

منصة تاريخية عربية تفاعلية تحتوي على:

- مكتبة كتب تاريخية
- موسوعة شخصيات
- قاعدة أحداث تاريخية
- خرائط تفاعلية
- خطوط زمنية
- صفحات تعريفية وتجارية
- تصدير للطباعة أو الحفظ بصيغة PDF

النسخة: 1.0

## تشغيل الموقع

لتحميل الكتب والشخصيات والأحداث من ملفات JSON، شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`؛ ستحولك الصفحة الرئيسية تلقائيًا إلى `website/index.html`. لا تفتح ملف HTML مباشرة؛ إذ تتطلب قراءة ملفات JSON تشغيل الموقع عبر خادم محلي.

تتضمن الواجهة صفحات مستقلة للرئيسية والكتب والشخصيات والأحداث والخرائط والخط الزمني. تشترك الصفحات في `website/styles.css` و`website/app.js`، ويُبنى الخط الزمني التفاعلي من `events/events.json` مع ترتيب الأحداث وإمكانية استعراضها حسب السنة. تستخدم صفحة الخرائط Leaflet وخرائط OpenStreetMap، لذا يلزم اتصال بالإنترنت لتحميل مكتبة الخريطة والبلاطات.

## البيانات

تحتوي البيانات على 120 كتابًا و550 شخصية و1,100 حدث. أُضيفت 20 بطاقة كتاب و50 شخصية و100 حدث بملخصات عربية وروابط إلى مقالاتها المرجعية في ويكيبيديا. روابط المصدر ظاهرة على البطاقات والخط الزمني، ومقالات ويكيبيديا مرخصة بموجب CC BY-SA 4.0؛ هذه البطاقات لا تعني أن النص الكامل للكتب متاح للتنزيل.

تظل السجلات الموسومة `isSample` بيانات مولّدة للاختبار، وليست حقائق تاريخية: 97 كتابًا و498 شخصية و998 حدثًا. تظهر لها شارة «تجريبي» في الواجهة. يشغّل `node scripts/import-verified-content.js` استيراد المجموعة الموثقة، ويعيد `node scripts/generate-sample-data.js` ضبط الأعداد والتحقق من وجود السجلات الموثقة وروابطها دون حذفها.

## التصدير والخطط

زر «طباعة / حفظ PDF» يستخدم نافذة الطباعة في المتصفح؛ اختر «حفظ كـ PDF». مجلد `exports` مخصص لحفظ الملفات يدويًا. صفحة الخطط تعريفية فقط: الدفع والاشتراكات ومزايا الخطة الاحترافية ليست مفعّلة. نموذج التواصل لا يرسل الرسائل حتى ربطه بخدمة استقبال.

## النشر على GitHub Pages

يوجد سير عمل في `.github/workflows/pages.yml` يفحص الملفات قبل النشر، ويستخدم إعداد GitHub Pages لتوليد عناوين SEO ومسار 404 الصحيح، ثم ينشر عند الدفع إلى فرع `main`. راجع [قائمة تحقق الإطلاق](LAUNCH_CHECKLIST.md) و[دليل النشر خطوة بخطوة](DEPLOY_GITHUB_PAGES.md).

للفحص المحلي قبل الدفع:

```powershell
node scripts/validate-launch.js
```

لتوليد ملفات SEO محليًا، عيّن `SITE_URL` إلى العنوان الأساسي المنشور ثم شغّل `node scripts/generate-seo.js`. راجع [خارطة الطريق](ROADMAP.md) للأولويات المقترحة للأشهر الستة القادمة.
